# エモカプセル

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
思いでの写真と同じポーズを、当時のメンバーがそろって再現したときだけ開く、みんなの写真フォルダです。
### 背景(製品開発のきっかけ、課題等）
卒業や就職、引っ越しで、昔の仲間と集まる機会はだんだん減っていきます。思い出の写真はそれぞれのスマホに残っていても、見返すことは少なく、「また集まろう」と言い出すきっかけもなかなかありません。
私たちは、思い出の写真そのものを「みんながもう一度集まる理由」にできないかと考えました。
### 製品説明（具体的な製品の説明）
昔の思い出の写真を「鍵」として登録すると、写真から当時の人数・立ち位置・ポーズ（肩を基準にした手やひじの位置）と顔が読み取られ、みんなで写真を入れられる共有フォルダが作られます。開けるときは当時のメンバーが揃ってあの日と同じポーズで撮影し、骨格と顔の照合で全員が一致したときだけロックが解除されて写真が見られます。

参照：内閣府孤独・孤立対策推進室, https://www.cao.go.jp/kodoku_koritsu/torikumi/zenkokuchousa/r7/pdf/tyosakekka_point.pdf
### 特長
#### 1. 思い出の写真が、そのまま「鍵」になる
写真を1枚選ぶだけで、写っている人数・立ち位置・ポーズを読み取って鍵にします。パスワードを決める必要はなく、あの日のポーズそのものが合言葉になります。
#### 2. 当時のメンバーがそろわないと開かない
骨格の位置に加えて顔も照合し、全員がそろったときだけフォルダが開きます。開けるたびに今の顔を覚え直すので、年月がたって見た目が変わっても開けられます。
#### 3. 失敗しても「あと少し」と声をかけてくれる
ずれている人と体の部位を「右の人のひじをもう少し上げて」のように伝え、何度でも撮り直せます。開いたときは贈りものを開けるような演出で、あの日の写真と今日の写真が並びます。

### 解決出来ること
* 「写真のポーズを再現しに集まろう」という、もう一度集まるための具体的なきっかけを作れます。
* それぞれのスマホに散らばっていた写真を、メンバー全員の共有フォルダに集められます。
* 一人では開けられないので、みんなの写真を「みんながそろったときに見る特別なもの」として残せます。
### 今後の展望
* Googleログイン（Amazon Cognito）に対応する
* カメラ画面で骨格をリアルタイムに重ね、ポーズ合わせを手伝う（MediaPipe）
* 開封日が近づいたらメンバーに知らせる（Amazon EventBridge Scheduler・Amazon SES）
* 離れて暮らすメンバーが、別々の場所で撮った写真を合わせて開けるようにする
### 注力したこと（こだわり等）
* 自由なポーズでも開けられる判定：関節の角度ではなく、両肩の中心から見たひじ・手首・ひざ・足首の位置で比べます。当時写っていない点は比べないので、片手を隠したポーズも鍵にできます。
* 近くに並んだ人の骨格を読み違えないように、姿勢推定を MediaPipe から RTMPose（人を見つけてから1人ずつ骨格を推定）に切り替えました。
* 顔の照合で入れ替わりやそっくりさんを防ぎつつ、顔の画像は保存せず、顔の特徴の数字だけを保存しています。
* 判定はすべてサーバーで行います。ブラウザから座標は受け取らず、写真から推定するので、ごまかせません。
* 失敗したときに「認証エラー」のような冷たい言葉を出さず、次に何をすればいいかを伝えます。

## 開発技術
### 活用した技術
#### API・データ
* Amazon S3（非公開。署名付きURLでブラウザから直接アップロード・閲覧）
* Amazon DynamoDB（1テーブル設計）
* AWS Lambda（コンテナイメージ）・Amazon API Gateway（HTTP API）・Amazon ECR
* 姿勢推定モデル：RTMPose-m、YOLOX-m（人の検出）
* 顔のモデル：OpenCV YuNet（顔の検出）、SFace（顔の特徴）

#### フレームワーク・ライブラリ・モジュール
* バックエンド：FastAPI、Mangum、Pydantic、rtmlib、ONNX Runtime、OpenCV、MediaPipe、NumPy、Pillow、boto3
* フロントエンド：React、TypeScript、Vite、React Router、lucide-react
* テスト：pytest、Vitest、ESLint

#### デバイス
* スマートフォン（ブラウザのカメラで撮影）
* PC（ブラウザ）

### 独自技術
#### ハッカソンで開発した独自機能・技術
* ポーズの照合（[backend/app/pose/matcher.py](backend/app/pose/matcher.py)、[backend/app/pose/angles.py](backend/app/pose/angles.py)）：肩幅を1として手足の位置を比べ、人数が同じで各人の平均のずれが0.35以内なら成功。失敗したときは、どの人のどの点がずれているかを返します（commit 2275bcc）。
* 複数人の骨格推定（[backend/app/pose/rtm_detector.py](backend/app/pose/rtm_detector.py)）：YOLOX-m で人を見つけてから RTMPose-m で1人ずつ推定し、最大4人を左から順に並べます。
* 顔の照合（[backend/app/pose/face.py](backend/app/pose/face.py)）：立ち位置ごとに、顔の記憶との類似度がしきい値以上で、ほかの人の記憶より十分よく似ているときだけ本人とみなします。開けるたびに顔の記憶を更新します（commit 2fcb906）。
* ポーズで開ける共有フォルダのAPI（[backend/app/routers/capsules.py](backend/app/routers/capsules.py)、仕様は [docs/api.md](docs/api.md)）：解除に成功した人にだけ、そのフォルダ用の解除トークンを発行します（commit 1683644）。
